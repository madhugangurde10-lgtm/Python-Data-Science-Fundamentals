# Diabetes Risk Analysis

## Project Overview

This project performs Exploratory Data Analysis on the Diabetes dataset to identify important patterns and insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Insight Generation

## Key Insights

- Glucose has a strong relationship with diabetes outcome.
- Age and BMI influence diabetes risk.
- Visualization helps understand patient patterns.
